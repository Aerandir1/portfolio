Comparateur de prix carburants

Cette page dédiée donne un accès direct à l'application Flask de recherche de stations-service. Elle reste aussi présente dans la section projets du portfolio, mais ici tu as une page complète pour la présenter, l'utiliser et la partager avec une URL courte.

Ouvrir dans un onglet Voir aussi dans les projets

Fonctionnalités

  • Recherche par ville ou code postal.
  • Filtrage par type de carburant.
  • Tri des stations par prix croissant.
  • Ouverture rapide dans Google Maps.
  • Actualisation manuelle des données open data.

À savoir

Cette page embarque l'application disponible localement sur 127.0.0.1:5000. Si rien ne s'affiche dans l'encadré ci-dessous, lance d'abord l'application avec python3 app/app.py depuis le dossier du portfolio.
