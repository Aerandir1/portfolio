Comparateur de prix carburants

Ce projet consiste en une application web front-end permettant de rechercher et comparer les prix des carburants dans les stations-service à proximité. L'application consomme les données ouvertes officielles en direct dans le navigateur et propose une interface conviviale pour trouver les meilleures offres.

Accéder à l'application Voir aussi dans les projets

Fonctionnalités

  • Recherche par ville ou code postal.
  • Filtrage par type de carburant.
  • Tri des stations par prix croissant.
  • Ouverture rapide dans Google Maps.
  • Actualisation manuelle des données open data.

À savoir

Cette version est 100% web: elle fonctionne directement sur Internet sans Flask, en chargeant les données open data en direct depuis la source officielle.
